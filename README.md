# Прораб — платформа управления ремонтными бригадами

Telegram-бот для прорабов и рабочих. SaaS-платформа.

## Роли

- **Прораб** — создаёт объекты, ставит задачи, добавляет рабочих, общается в чате
- **Рабочий** — получает задачи, берёт в работу, отмечает выполнение с фото, общается в чате

## Функциональность

### Прораб
- Создать объект (название + адрес)
- Получить инвайт-ссылку для рабочих (автодобавление при переходе)
- Добавить рабочего по номеру телефона
- Создать задачу на объект → рабочие получают push-уведомление
- Просматривать статус задач
- Получать фото-отчёт о выполнении задачи
- Общий чат объекта

### Рабочий
- Регистрация по телефону
- Присоединение к объекту по инвайт-ссылке (автоматически при старте)
- Просмотр задач объекта
- Взять задачу → прораб получает push
- Отметить задачу выполненной: фото (1–5) + комментарий → прораб получает уведомление
- Общий чат объекта

## Стек

- Python 3.11+
- aiogram 3.x
- SQLAlchemy 2.0 async
- SQLite (dev) / PostgreSQL (prod)

## Запуск

```bash
cp .env.example .env
# Заполнить BOT_TOKEN в .env
pip install -r requirements.txt
python bot.py
```

## Структура БД

```
users          — прорабы и рабочие (telegram_id, phone, name, role)
sites          — объекты (название, адрес, прораб, invite_code)
site_members   — связь рабочих с объектами (многие-ко-многим)
tasks          — задачи (объект, статус: open/in_progress/done)
task_reports   — отчёты о выполнении (фото, комментарий)
messages       — чат объекта
```
